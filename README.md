### Full Stack Developer who cares more about the last 10% than the first 90%.

I build with Next.js and TypeScript, but the part I actually obsess over is
what happens after the feature "works" — the spacing that's a pixel off,
the transition that's 40ms too slow, the empty state nobody designed.
That gap is where I spend most of my time.

Right now I'm building **PULSE**, a premium fitness tracker PWA with
offline support, install-on-device capability, and a dark/light theme
system I've broken and fixed more times than I'd like to admit — which
is exactly how you learn what actually goes wrong in production UI.

**Based in:** Pakistan 🇵🇰
**Building:** PULSE 💓 · [3D Portfolio](https://3d-portfolio-seven-beta-14.vercel.app/)
**Learning:** Three.js, WebGL shaders, system design
